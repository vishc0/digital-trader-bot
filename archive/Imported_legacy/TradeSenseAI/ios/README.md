## Setup

1. Install Xcode 15.0+
2. Open `TradeSenseAI.xcodeproj`
3. Select target device (iPhone 15 Pro simulator)
4. Press ⌘+R to build and run

## Requirements

- macOS 13.0+ (Ventura or later)
- Xcode 15.0+
- iOS 17.0+ deployment target
- Swift 5.9+

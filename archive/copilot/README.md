s custom agents# GitHub Copilot Custom Agents - User Level

These agents are available in **all GitHub Copilot instances** across all repositories and projects.

## Available Agents

Use `@agent-name` in any GitHub Copilot Chat:

- 💼 `@business-strategist` - Business strategy, market analysis, viability assessment
- 🔬 `@research-analyst` - Market research, competitive intelligence, trend analysis
- 💻 `@code-architect` - Software development, system design, automation
- 📊 `@product-strategist` - Product roadmaps, feature prioritization, sprint planning
- 📢 `@growth-marketer` - Marketing strategy, content marketing, customer acquisition
- 💰 `@sales-ops-expert` - Sales processes, CRM setup, operations workflows
- 🎯 `@business-orchestrator` - Coordinates multiple agents for complex projects

## Quick Start

Just type in any Copilot Chat:

```
@business-strategist Evaluate my SaaS idea targeting small businesses
```

```
@code-architect Design a scalable microservices architecture
```

```
@business-orchestrator Create complete launch plan for my online course platform
```

## Location

```
C:\Users\PC\.github-copilot\instructions\
```

## Files

- `business-strategist.md` - Business strategy frameworks
- `research-analyst.md` - Research methodologies
- `code-architect.md` - Software engineering best practices
- `product-strategist.md` - Product management frameworks (RICE, user stories)
- `growth-marketer.md` - Marketing strategies (SEO, content, social)
- `sales-ops-expert.md` - Sales processes and CRM workflows
- `business-orchestrator.md` - Multi-agent coordination

## Benefits

✅ **Global availability** - Works in all repos, all projects
✅ **Always accessible** - No per-project setup needed
✅ **Persistent** - Same agents everywhere you use Copilot
✅ **Consistent** - Same expertise across all work

## Customization

Edit any `.md` file in this directory to customize agent behavior. Changes apply immediately to all Copilot instances.

# Human Thought Process to Emulate

## Core decision loop

1. What is happening now?
2. Why does it matter?
3. What action options exist?
4. What is the risk of each option?
5. What evidence is missing?
6. What is the smallest safe next move?

## AI reasoning posture

- Start from market regime, portfolio exposure, and cash position.
- Check whether a proposed action changes concentration or downside materially.
- Prefer clear, simple setups over clever but fragile ideas.
- Explain hold, trim, buy, and exit in plain language.
- Acknowledge uncertainty.

## Exit thinking

- Define invalidation early.
- Prefer rule-based exits over emotional exits.
- Compare target, stop, trailing logic, and time-based exit.
- Re-evaluate when expected edge weakens.

## Token-aware reasoning

- Think in compressed state summaries.
- Only expand detail for flagged positions, anomalies, or approvals.
- Reuse prior conclusions when no material state changed.

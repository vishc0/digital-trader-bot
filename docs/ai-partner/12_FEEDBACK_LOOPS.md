# Feedback Loops

## Product loop

- Capture operator pain points.
- Convert into backlog items.
- Measure adoption and time saved.

## Trading loop

- Compare expected vs actual P&L.
- Track false positives, late exits, and missed exits.
- Feed post-trade analysis into strategy review.

## AI loop

- Evaluate advice quality, hallucination rate, latency, and token cost.
- Store prompt version and model version.
- Promote only evaluated prompt changes.

## Reliability loop

- Review incidents weekly.
- Track MTTR, failed orders, stale data, and alert fatigue.
- Turn incidents into runbooks and automated checks.

## Governance loop

- Review risk and compliance exceptions.
- Review approval bypass attempts and rejected orders.
- Confirm no workflow encourages rule evasion.

# AI Partner Documentation

This folder defines how AI should help build and operate Digital Trader Bot.

## Core principle

Token efficiency is a platform goal, not just an implementation detail.

Project memory must also be maintained in `.github/MemoryPrint` as compact machine-readable checkpoints so AI can restore project context quickly across sessions.

## 1-Hour Daily Plan

### Structure (60 minutes total)

- 10 min: Review prior day chart notes and mistakes.
- 20 min: Learn one concept from the current topic file.
- 20 min: Replay/annotate 1-2 charts applying that concept.
- 10 min: Journal one executable rule and one do-not-do rule.

## Weekly Gap Review

- Can I define setup context in one sentence (trend + level + catalyst)?
- Can I define invalidation before entry every time?
- Do I know whether my last 20 trades were continuation or reversal trades?
- Do I know my best setup by expectancy, not by win rate?
- Am I skipping low-quality charts or overtrading noise?

If any answer is no, return to the relevant topic and tighten rules.
